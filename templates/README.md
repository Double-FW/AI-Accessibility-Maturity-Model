# Assessment working templates

Use the templates in order with the [assessment runbook](../ASSESSMENT_RUNBOOK.md). These are blank record structures, not completed decisions or a software schema. Store real records in approved organisational systems. Keep personal material out of public GitHub issues, this repository and unapproved AI services.

| Record | Use |
| --- | --- |
| [Assessment brief](assessment-brief.md) | Scope, decision authority, people, sampling and participation |
| [Evidence register](evidence-register.md) | Source/provenance, strand/cell assertions, contradictions and limits |
| [Decision record](decision-record.md) | Provisional profile, challenge, actual authority and source conflicts |
| [Improvement plan](improvement-plan.md) | Outcomes, receiving owners, resources, actions and retest |
| [Report](report.md) | Bounded six-dimension findings, evidence limits and next decisions |

Use locally unique record IDs such as A001, E001, Q001 and I001. These examples are not global repository test IDs. One evidence item may support several distinct scoped assertions. Preserve exact links and versions, and do not count duplicated copies as independent evidence.

Do not leave important blanks ambiguous: use Unknown, Not assessed, Insufficient evidence or Not applicable with rationale as appropriate. A named role or signature line is not proof that someone accepted responsibility.
